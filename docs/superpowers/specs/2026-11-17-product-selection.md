# Seleção de equipamentos • melhoria imediata

O vendedor deve encontrar e incluir equipamentos pelo nome ou código sem perder o contexto do pedido. A lista deve abrir sobre o conteúdo, ter altura limitada e rolagem própria, exibir foto disponível, nome, SKU, linha e preço com IPI. Ao focar a busca vazia, mostrar opções disponíveis. Busca deve ignorar acentos e permitir palavras em qualquer ordem. Setas navegam, Enter inclui a opção ativa e Esc fecha. Após incluir, manter foco na busca para incluir o próximo produto; repetição acrescenta quantidade conforme o comportamento existente. Nada de seleção global de tabela: nacional e importada convivem.

Identificadores históricos de produtos aceitos por PostgreSQL e pela API Rust devem continuar aceitos na API TypeScript, inclusive UUIDs com variante não RFC. Não alterar IDs ou dados comerciais no banco. Rejeitar identificadores malformados. Preservar autorização, isolamento da empresa e validação estrita das chaves de idempotência. A linha nacional não possui cores.

Usar os dados e imagens já disponíveis, sem inventar fotos, preços ou características. Preservar o pedido em edição, sem salvamento automático ou envio real. Textos novos usam • como separador.
